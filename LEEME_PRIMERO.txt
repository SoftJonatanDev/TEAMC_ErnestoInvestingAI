ERNESTO INVESTING AI - INTERFAZ SIMULADA v2

1. Extrae TODO el ZIP. No abras archivos dentro del ZIP.
2. Abre una terminal en esta carpeta (la que contiene iniciar.py).
3. Ejecuta:

   Windows:     py iniciar.py
   macOS/Linux: python3 iniciar.py

   Tambien puedes abrir INICIAR_WINDOWS.bat en Windows con Python 3 instalado.
   El iniciador abre el navegador y muestra la direccion correcta en la terminal.
   Deja esa terminal abierta. Ctrl+C detiene el servidor.

ALTERNATIVA:
   python -m http.server 8000 --bind 127.0.0.1
   Abre http://127.0.0.1:8000

IMPORTANTE:
- La interfaz mejorada se abre desde ESTA carpeta, no desde figma-src.
- No necesita npm, pnpm, Node.js, base de datos ni claves de API.
- No abras index.html por doble clic: la carga de JSON necesita HTTP local.
- Incluye graficos locales. No necesita Internet para funcionar.
- Todos los precios dinamicos, ordenes y alertas son simulaciones educativas.
- Si ya usaste una version anterior, Trading > Restablecer cuenta permite
  empezar otra vez con el efectivo y las posiciones originales.
- Usa la misma direccion, puerto y navegador para conservar tu cuenta local.

Mira README.md, CAMBIOS_INTERFAZ.md y docs/VALIDACION.md para mas detalles.
